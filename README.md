# Meterly

**An API-first usage metering platform for B2B SaaS applications.**

## Overview

Meterly is a usage metering service designed to help SaaS teams track and aggregate customer usage, prevent double counting, and monitor usage quotas.

The platform focuses on **usage metering rather than billing or payment processing**.

### MVP Scope

The MVP focuses on two end-to-end scenarios:

1. **Usage event processing:** Ingest, validate, deduplicate, and aggregate customer usage events.
2. **Usage monitoring and quota management:** Configure usage limits, retrieve aggregated usage, and check quota status.

Detailed functional requirements, acceptance criteria, and scope boundaries are documented in the [Product Brief](docs/product/brief.md) and [User Stories](docs/requirements/stories.md).
